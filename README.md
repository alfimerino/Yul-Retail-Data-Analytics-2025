# Yul Retail Data Analytics 2025
Project Overview: Yul K-Beauty Retail Analytics This project focuses on transforming raw transactional data from a K-Beauty retail environment into actionable financial insights. Using Azure SQL Database and Power BI, I engineered a data pipeline to calculate critical business KPIs, including net revenue, gross margins, and the impact of promotional discounting on overall profitability.  Key Features & Analysis Financial Performance Modeling: Developed complex SQL views to calculate Net Revenue and Net Profit, specifically accounting for decimal-based discount structures.  Retail KPI Engineering: Built logic for essential retail metrics such as Average Order Value (AOV), Cost of Goods Sold (COGS), and Gross Margin Percentages.  Product & Customer Insights: Analyzed sales performance across diverse categories (Skincare, Haircare) and customer segments, including trends related to specific Skin Types.  Data Optimization: Utilized Azure Query Editor to refine data types and ensure 100% accuracy in financial reporting, handling edge cases like zero-sales days with error-handling logic (NULLIF).  Technical Stack Database: Azure SQL (T-SQL)  Analytics Tool: Power BI / DAX  Environment: Microsoft Azure Cloud
